## Recommended Free Sources

### Background Music (Royalty-Free)
1. **Pixabay Music** - https://pixabay.com/music/
   - Search: "game music", "lo-fi", "chiptune", "casual game"
   - Recommended: Lo-fi chill beats, 8-bit game music

2. **OpenGameArt** - https://opengameart.org/
   - Great for retro/chiptune style

3. **Free Music Archive** - https://freemusicarchive.org/
   - Filter by license: CC0 or CC-BY

### Sound Effects
1. **Freesound** - https://freesound.org/
   - Huge library, search by effect name

2. **Mixkit** - https://mixkit.co/free-sound-effects/
   - High quality, no attribution required

3. **Zapsplat** - https://www.zapsplat.com/
   - Free with attribution (or paid for no attribution)

4. **Kenney.nl** - https://kenney.nl/assets?q=audio
   - Game-ready sound packs, CC0 license

## Quick Download Pack (Recommended)

For fastest setup, download these free packs:

1. **Kenney Interface Sounds**: https://kenney.nl/assets/interface-sounds
   - Contains: click, hover, select, close, open

2. **Kenney Game Sounds**: https://kenney.nl/assets/game-sounds
   - Contains: correct, wrong, coin, level-up

3. **Search Freesound for specific sounds**:
   - "countdown beep" for countdown
   - "card flip" for card-flip
   - "victory fanfare" for victory
   - "game over" for game-over

## Audio Specifications

- **Format**: MP3 (best compatibility)
- **Bitrate**: 128-192 kbps (balance quality/size)
- **Music duration**: 1-3 minutes (will loop)
- **SFX duration**: < 2 seconds (except victory/game-over)

## File Size Guidelines

- Keep individual SFX files under 50KB
- Music files: 1-3 MB each
- Total audio folder: < 10 MB for fast loading
